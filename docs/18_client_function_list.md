株式會社 談 様向け｜作成日: 2026-08-07

---

## 1. この資料について

新システムで提供する機能の全体像と、現在の進み具合を一覧にしたものです。当初いただいた改善ご要望（24項目）と、7月23日にいただいた追加ご要望（20項目）の両方を機能として織り込んでいます。

### 1.1 状態の見方

| 表示 | 意味 |
|------|------|
| ✅ | できています（実際の画面でお見せできます） |
| 🔶 | 途中まで（土台はできていますが、中心部分が未完成です） |
| ⬜ | これから（未着手です） |

### 1.2 区分の見方

| 表示 | 意味 |
|------|------|
| 踏襲 | 現行システムにある機能をそのまま引き継ぎます |
| 改善 | 現行にある機能を、ご要望に沿って作り直します |
| 新規 | 現行にない機能を新しく作ります |

### 1.3 リリース段階

| 段階 | 内容 |
|------|------|
| 第1弾 | ログイン・設定・受注・献立資料・盛付指示書 |
| 第2弾 | 発注・在庫、製造・配送帳票、請求 |
| 第3弾 | 新しい業務（特別注文・試食会）、現場業務 |
| 第4弾 | AI活用（方針決定後） |

## 4. 現行システムから無くなるもの

| 無くなるもの | 理由 |
|------------|------|
| 編集業者の選択（ログイン直後のロック取得） | 業者ロックを廃止するため不要になります。ログイン後すぐ業務画面に入れます |
| 編集可能業者の解除 | 同上。ロックが無いので解除も不要です |
| データベース管理画面 | 設定画面に機能を吸収します。チェックを通さない直接編集をなくします |
| ソーシャルログインのボタン | 現行は押しても動作していないため、実装しません |
| IPアドレス直打ち・暗号化なしの在庫システム | 基幹システムと同じドメインに統合し、通信を暗号化します |

## 5. リリース段階のまとめ

| 段階 | 含まれる分野 | 主な効果 |
|------|------------|---------|
| **第1弾** | ログイン・設定・受注・献立資料・盛付指示書 | 締切の設定変更が自分でできる。注文画面が使える。過去の資料が変わらない。ユニット数の上限がなくなる |
| **第2弾** | 発注・在庫、製造・配送帳票、請求 | 発注画面が軽くなり同時作業ができる。佐川伝票が自動化。請求書を施設ごとに確認できる |
| **第3弾** | 特別注文・試食会・現場業務 | おせち容器のFAXがなくなる。試食会に対応。チラー枠・箱サイズ |
| **第4弾** | AI活用 | 返信案・照合・再振り分けなどの自動化 |
