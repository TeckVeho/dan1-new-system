# 14. 未決事項・確認事項

作成日: 2026-08-04｜最終更新: 2026-08-13

各ドキュメントの `[要確認]` を集約した。当初は要件定義の合意前確認リストだったが、**第1弾はほぼ実装済み・第2弾は仮仕様まで進行**している。未決のまま実装で仮決めした項目と、本番ロジックにまだ必要な確認を区別する。

**優先度の定義**

| 優先度 | 意味 |
|-------|------|
| **S** | 確認できないと本番ロジック（発注量計算・帳票本フォーマット・移行）を確定できない。最優先 |
| A | 設計・本実装に影響する。該当機能の本完成前に必要 |
| B | 実装時に必要。並行して確認可能 |
| C | 運用開始までに決めれば足りる |

**状態の定義**

| 表示 | 意味 |
|------|------|
| 未決 | クライアント確認がまだない |
| 仮決定 | 新システム側で仮定して実装済み。事後確認が必要 |
| 解消 | 新システムの設計ブロックとしては閉じた（現行システムの調査・移行確認が残る場合あり） |

番号（Q-01〜）は他ドキュメントからの参照を維持するため変えない。

## 0. いまの位置づけ（2026-08-13）

画面・マスタ・受注は仮決めして先行実装済みである。優先度 S・A の確認は **「開発着手の前提」ではなく「本番ロジック・移行・外部連携の確定」** に必要。

| 区分 | 内容 |
|------|------|
| 待たずに着手できる | 操作マニュアル PDF、請求の施設グループ一括選択、Excel 出力の仕上げ |
| 仮実装の延長は可能 | らくらく取込 UI、発注スケジュールの磨き込み、製造帳票の仮フォーマット改善。本完成は実物待ち |
| 本実装は確認待ち | 発注量の自動計算（Q-01, Q-08, Q-09）、らくらくパース（Q-22）、佐川（Q-16, Q-17）、QR（Q-12, Q-18〜Q-21）、ロット発注書（Q-59）、データ移行（Q-02）、本番基盤（Q-24〜Q-26） |

機能の進み具合は `18_client_function_list.md` を正とする。
